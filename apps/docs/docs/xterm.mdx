`attachJustBashTerminal()` is the default integration. It opens the OPFS workspace,
creates `Bash`, binds raw terminal input to the shell, handles history and `cd`,
normalizes terminal output, and closes everything together. xterm.js stays a
renderer dependency, not an `opfs-fs` dependency.

```sh
npm install @kucukkanat/opfs-fs@github:kucukkanat/opfs-fs#main just-bash @xterm/xterm @xterm/addon-fit react react-dom
```

## Editable live example

The editor below is the executable source—not a second, illustrative version.
It runs the exact `attachJustBashTerminal()` call it displays. Edit the
workspace name, banner, initialization, or any other supported option, then run
it to replace the terminal session. The playground injects only the xterm
`terminal` port and the imported `attachJustBashTerminal` function.

<XtermPlayground />

The returned `shell` exposes `workspace`, `bash`, `cwd`, and `execute(command)`
when you need an escape hatch. Type `help`, `pwd`, `ls`, `cat welcome.txt`, or
`printf hello > note.txt`; reload and `cat note.txt` to verify OPFS persistence.

:::tip
Use `createJustBashFileSystem()` and `createJustBashTerminalSession()` directly
only when you need a custom shell lifecycle or input policy.
:::
