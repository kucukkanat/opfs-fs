`attachJustBashTerminal()` is the default integration. It opens the OPFS workspace,
creates `Bash`, binds raw terminal input to the shell, handles history and `cd`,
normalizes terminal output, and closes everything together. xterm.js stays a
renderer dependency, not an `opfs-fs` dependency.

```sh
npm install @kucukkanat/opfs-fs@github:kucukkanat/opfs-fs#main just-bash @xterm/xterm @xterm/addon-fit react react-dom
```

Apply the [browser compression alias](/opfs-fs/just-bash/#browser-bundlers-and-compression) before running this example.

## Complete integration

```tsx
import { installBrowserBuffer } from "@kucukkanat/opfs-fs/browser-zlib"
import { useEffect, useRef } from "react"
import { FitAddon } from "@xterm/addon-fit"
import { Terminal } from "@xterm/xterm"
import "@xterm/xterm/css/xterm.css"
import {
  attachJustBashTerminal,
  type AttachedJustBashTerminal,
} from "@kucukkanat/opfs-fs/just-bash"

export function OpfsXterm() {
  const host = useRef<HTMLDivElement | null>(null)

  useEffect(() => {
    installBrowserBuffer()
    const target = host.current
    if (!target) return

    const terminal = new Terminal({ cursorBlink: true, screenReaderMode: true, rows: 18 })
    const fit = new FitAddon()
    terminal.loadAddon(fit)
    terminal.open(target)
    fit.fit()

    const resized = new ResizeObserver(() => fit.fit())
    resized.observe(target)
    let disposed = false
    let shell: AttachedJustBashTerminal | undefined
    const close = (session: AttachedJustBashTerminal) => {
      void Promise.resolve(session.dispose()).catch(console.error)
    }

    void attachJustBashTerminal({
      terminal: {
        write: (value) => { if (!disposed) terminal.write(value) },
        onData: (callback) => disposed ? { dispose: () => {} } : terminal.onData(callback),
      },
      workspace: { name: "terminal", root: "/workspace" },
      executionLimitProfile: "hardened",
      banner: "Durable OPFS terminal",
      initialize: async ({ workspace }) => {
        await workspace.writeFile("/workspace/welcome.txt", "Hello from OPFS\n")
      },
    }).then(
      (attached) => {
        shell = attached
        if (disposed) close(shell)
      },
      (error: unknown) => { if (!disposed) terminal.write(`Unable to open OPFS: ${String(error)}\r\n`) },
    )

    return () => {
      disposed = true
      resized.disconnect()
      if (shell) close(shell)
      terminal.dispose()
    }
  }, [])

  return <div ref={host} style={{ minHeight: 360 }} />
}
```

## Editable live example

The complete example above is the renderer setup; the editable program below
is its `attachJustBashTerminal()` call. It runs that exact program. Edit the
workspace name, banner, initialization, or any other supported option, then
run it to replace the terminal session. The playground injects only the xterm
`terminal` port and the imported `attachJustBashTerminal` function.

<XtermPlayground />

The returned `shell` exposes `workspace`, `bash`, `cwd`, and `execute(command)`
when you need an escape hatch. Type `help`, `pwd`, `ls`, `cat welcome.txt`, or
`printf hello > note.txt`; reload and `cat note.txt` to verify OPFS persistence.

:::tip
Use `createJustBashFileSystem()` and `createJustBashTerminalSession()` directly
only when you need a custom shell lifecycle or input policy.
:::
