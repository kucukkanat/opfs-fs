Give browser agents and local-first applications a persistent workspace. Write files, run `just-bash` commands against the same tree, and reopen your project after a reload. Transactions group related edits; TAR export makes the files portable.

## Try it in your browser

Edit this file, save it, then reload the page. The editor restores the saved content from OPFS without a server.

:::warning
OPFS data belongs to the current origin. Use the explicit export/reset APIs for user-controlled portability and deletion.
:::

## Install from GitHub

The repository commits the package's ESM build and exposes it from the Git
dependency root, so install it under its public scoped name:

```sh
npm install @kucukkanat/opfs-fs@github:kucukkanat/opfs-fs#main
```

The `#main` form follows the latest build. Pin a commit for reproducible builds:

```json
{
  "dependencies": {
    "@kucukkanat/opfs-fs": "github:kucukkanat/opfs-fs#9517c13"
  }
}
```

With Bun, use the same dependency specifier:

```sh
bun add @kucukkanat/opfs-fs@github:kucukkanat/opfs-fs#main
```

The import paths are the same for a Git dependency and an npm registry release.
The monorepo layout is an implementation detail; consumers only use the public
package and documented subpaths.

## Open a workspace

```ts
import { openWorkspace } from "@kucukkanat/opfs-fs"

const fs = await openWorkspace({
  name: "agent-workspace",
  root: "/workspace",
})

await fs.writeFile("/workspace/README.md", "# Durable browser workspace\n")
```

Every individual mutation auto-commits. Use `transaction()` when several changes must become visible together.

```ts
await fs.transaction(async (tx) => {
  await tx.mkdir("/workspace/src", { recursive: true })
  await tx.mv("/workspace/README.md", "/workspace/src/README.md")
})
```

For a single browser application flow covering files, bytes, metadata, links, transactions, archive recovery, storage, typed errors, and `just-bash`, see the [complete example](/opfs-fs/complete-example/).

## Choose your integration

- [React lifecycle](/opfs-fs/react/): open on the client and dispose safely.
- [just-bash](/opfs-fs/just-bash/), [xterm.js](/opfs-fs/xterm/) and [wterm](/opfs-fs/wterm/): execute commands and render a terminal.
- [Browser agents](/opfs-fs/agents/): connect AI SDK tools and fx.sh host tools to persisted files.
- [API reference](/opfs-fs/api/) and [operations](/opfs-fs/lifecycle/): understand filesystem semantics, storage limits and recovery.

The demo uses a named workspace unique to this browser profile and origin. Browser storage can still be cleared or evicted; export important work. See [environment requirements](/opfs-fs/lifecycle/#environment-requirements) before shipping.


## Run the starter locally

Clone the repository and run its self-contained browser example:

```sh
git clone https://github.com/kucukkanat/opfs-fs.git
cd opfs-fs
bun install
bun run example
```

Open the localhost URL printed by the command. The [browser-agent example source](https://github.com/kucukkanat/opfs-fs/tree/main/examples/browser-agent) includes the browser bundler configuration; use it as a starting point for your own project.
